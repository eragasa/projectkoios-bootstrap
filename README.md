# projectkoios-bootstrap

The three-harness meta-harness for building and operating Project Koios.

| Harness | Tool | Domain |
|---------|------|--------|
| `archon/` | Archon (archon.diy) | Architecture design, ADRs, planning |
| `opencode/` | opencode | Code implementation, tests, validation, runtime |
| `goose/` | Goose (aaif-goose/goose) | Knowledge curation, vault ops, UI bootstrap |

See `architecture/adr.20260628.md` for the full decision record.
