## Files changed

### Bugfix: `_check_tmux()` false negative

**File:** `src/python/projectkoios/bootstrap/commands/harnesses.py`

`tmux --version` returns non-zero on tmux 3.7 (uses `-V` instead).
`_check_tmux()` caught the `CalledProcessError` and reported "tmux is not
installed or not on PATH" — a false negative blocking all `harnesses` commands.

Changed `["tmux", "--version"]` → `["tmux", "-V"]`.
