## Files changed

### Bugfix: `REPO_ROOT` resolution in `models.py`

**File:** `src/python/projectkoios/bootstrap/models.py:21-22`

`GLOBAL_DIR` was calculated via 5 `.parent` hops from `models.py`, then `REPO_ROOT` derived as `GLOBAL_DIR.parent` — producing `repo-root/agents/` instead of the repo root. Swapped to compute `REPO_ROOT` first, then derive `GLOBAL_DIR`.

This fix is required for the validator CLI to work at all: `projectkoios bootstrap validate-harnesses` was walking the wrong root directory and reporting 15 false-positive `missing canonical harness file` errors against the `agents/` folder.
