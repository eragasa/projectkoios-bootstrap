# Operator Console P0 fixtures

These fixtures are deterministic bootstrap-incubation data for the P0 Operator Console review flow.

They are not live Project Koios operational state. They are not product authority. Browser/provider code imports copied fixture data and does not read repository files, sessions, terminals, intercom, network resources, or external systems at runtime.

Every fixture source artifact records:

- locator/path;
- artifact type;
- source/content hash;
- captured/generated timestamp;
- transformation or excerpt notes;
- authority boundary.

Displayed evidence items are labeled as `copied-from-bootstrap`, `transformed-from-bootstrap`, or `synthetic`.
