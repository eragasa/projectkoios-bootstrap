# Research support

Use this prompt when Archon or the user needs research, note curation, or source-ingestion support before planning or implementation.

## Deliverables

Produce:
1. a concise summary of relevant findings
2. linked source notes or references
3. unresolved questions or contradictions
4. a recommendation for next routing:
   - back to `archon/` for planning/decision
   - to `opencode/` for implementation
   - remain in `goose/` for more curation

## Focus

Prioritize:
- source provenance
- note structure that can be reused later
- explicit uncertainty
- handoff readiness for downstream harnesses

## Do not do

- do not implement code changes as a substitute for research
- do not create architecture decisions unless explicitly asked to draft decision support material
- do not write to the vault unless the user asked for artifact generation or curation output
