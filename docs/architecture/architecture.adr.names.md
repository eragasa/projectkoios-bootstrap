# ADR Names

## Purpose

This is the bootstrap architecture note for ADR naming semantics.

## Scope

It indexes the semantic naming surface for ADR titles and filenames and points to the accepted ADR that owns the umbrella title-vs-filename distinction.

## Notes

- The accepted ADR is canonical only for the umbrella distinction between semantic title and storage filename.
- Detailed title and filename rules remain non-canonical draft guidance until separately accepted, revised, or rejected.
- This note MUST NOT be read as promoting the older draft filename model over the accepted ADR's bounded filename correction.
