# Architecture task: Archon artifact import command

## Objective

Specify a command that imports handoff artifacts produced inside an Archon
isolated worktree back into the main `projectkoios-bootstrap` workspace.

## Context

The current Archon run completed successfully and wrote an artifact to its
isolated worktree:

```text
/Users/eugene/.archon/workspaces/repos/projectkoios-bootstrap/worktrees/archon/task-projectkoios-current-state-routing/archon/handoffs/20260630.031500_projectkoios-current-state-clarification.md
```

Codex manually copied the artifact into the main workspace and committed it.
This should be a repeatable operator command.

## Candidate command shape

```bash
projectkoios bootstrap archon-import <run-id>
```

Possible options:

```bash
--kind handoff
--from archon/handoffs
--dry-run
--mark-source-complete
```

## Architecture questions

- Should this live under `projectkoios bootstrap archon-import` or under a
  broader `projectkoios bootstrap handoff import` namespace?
- How should the command discover the Archon worktree path from a run id?
- Should it import all new artifacts or require an explicit artifact path?
- How should conflicts be handled when the target path already exists?
- Should it update the source routing handoff status from active to complete?

## Expected Archon output

- architecture-spec
- acceptance-criteria
- implementation-brief
- safety constraints
- recommended CLI shape
- non-goals

## Initial acceptance criteria

- Given a completed Archon run id, the command can locate the run worktree.
- The command can list candidate artifacts before copying.
- The command can copy selected `archon/handoffs/*.md` artifacts into the main
  workspace.
- The command never overwrites an existing main-workspace artifact without an
  explicit force flag.
- The command prints follow-up validation and commit suggestions.

## Non-goals

- Do not delete Archon worktrees.
- Do not merge branches.
- Do not automatically commit imported artifacts.
- Do not import arbitrary files outside approved artifact directories.
