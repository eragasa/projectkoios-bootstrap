## Key decisions

- **`Marking` generic refactor**: `Marking` → `Marking[T]` with `HandoffMarking` alias. Minimal change to enable CPN type reuse without a parallel marking type. All existing tests pass unchanged.
- **Module path `harness/daemon/`**: co-located with CPN types in `harness/data/` and `harness/handoffs/`. No `projectkoios.ingestion` Python package created.
- **CLI verb `ingestion`**: top-level parser branch, not under `bootstrap`. The word `ingestion` appears only as a CLI verb.
- **Stdlib-only**: no new pip dependencies. `urllib` for Ollama, `asyncio` for watcher, `subprocess` for Graphify and git.
- **Ollama degrade**: if unreachable, warns and skips chunk cards; graph snapshot stays fresh.
- **Source-tree safety**: `git status --short` checked before and after each run; `graphify-out/` changes ignored; unexpected changes added as warnings to metadata.
