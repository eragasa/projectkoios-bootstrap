## What was built

1. **`src/python/projectkoios/bootstrap/harness/headers.py`** — Pure-function header extraction extracted from `HandoffParser._extract_frontmatter`. Exports `HEADER_FIELD_PATTERN` regex and `extract_handoff_headers(text: str) -> dict[str, str]`. Stdlib only.

2. **`SKILL.md`** — 7-section session protocol with routing table, Archon preflight/monitoring, fast fallback, handoff creation discipline, and stop conditions.

3. **`references/projectkoios-routing.md`** — Routing table mapping harness → role, artifact ownership, and when to bypass specialist routing.

4. **`references/archon-run-failure-modes.md`** — 7 documented failure modes with symptoms, fixes, and the fast fallback rule.

5. **`handoff_new.py`** — Slugify, header rendering, and CLI for creating handoff files with correct naming and headers. Pure functions are unit-testable.

6. **`session_scan.py`** — Scans handoff directories, parses headers via shared module, groups by Status, emits text or JSON. Includes git branch/status.

7. **`archon_run_watch.py`** — Dependency-injected Archon CLI runner, stale-run detection (PID check + status check), optional auto-abandon. All I/O is routed through `run_archon()` for testability.

8. **33 tests** (21 new + 52 existing = 73 total) covering slug generation, header rendering, header parsing, status grouping, stale detection, error paths, and CLI integration.
