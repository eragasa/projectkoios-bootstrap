# AAR 20260701.135948: Architecture formatting instructions

## Scope

Added a template instruction file for formatting changes to architecture notes.

## What happened

Created `docs/templates/architecture.template.instructions.md` to capture the
preferred structure for `architecture.*` notes: frontmatter, timestamped date,
human-readable title, and link rules.

## Process issues

- Formatting guidance was being repeated ad hoc in the conversation.
- A durable template instruction file is a better place for note-format rules.

## Proposed follow-up improvements

- Reference this template from future architecture note edits.
- Add any workspace-specific formatting rules here rather than scattering them
  across individual notes.

## Candidate ADR or implementation topics

- Architecture note template application workflow.

## Current status

Complete.
