# AAR 20260701.141202: Weighted rubric with human override

## Scope

Refined the debt triage model to use a weighted rubric with human override.

## What happened

Recorded the user's preference for a weighted rubric around leverage, effort, and structural importance, with urgency as a tie-breaker. Updated the deep-interview skill to include the weighted rubric in its deliverable shape.

## Process issues

No durable process issue observed.

## Proposed follow-up improvements

- Define concrete scoring ranges for leverage, effort, and structural importance.
- Consider whether urgency belongs as a score or only as a tie-breaker.

## Candidate ADR or implementation topics

- Debt triage weighted rubric.
- Human override and prioritization rules.

## Current status

The triage rubric now centers on leverage, effort, and structural importance.
