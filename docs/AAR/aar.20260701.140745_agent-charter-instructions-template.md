# AAR 20260701.140745: Agent charter instructions template

## Scope

Added a dedicated template instruction file for edits to the agent charter and
related routing notes.

## What happened

Created `docs/templates/agents.charter.instructions.md` so charter-formatting and
routing-rule changes have a durable place to record the conventions.

## Process issues

- Charter-formatting guidance had been living only in the conversation and the
charter itself.
- A separate template instruction file makes the rule easier to reuse.

## Proposed follow-up improvements

- Consider linking this template from `docs/agent-charter.md` if the charter
needs a direct pointer to its formatting rules.
- Add a similar template for other policy-style bootstrap notes if needed.

## Candidate ADR or implementation topics

- Bootstrap policy-note template structure.

## Current status

Complete.
