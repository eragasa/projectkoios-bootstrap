# AAR 20260701.142323: Scenario-first interview reset

## Scope

Shifted the deep-interview skill from abstract taxonomy toward scenario-driven questioning.

## What happened

The user pointed out that the interview questions were too vague for a problem that is not yet specific. I updated the deep-interview skill to require concrete scenario cards before abstract taxonomy, and seeded the working interview note with scenario cards for policy-goals, debt-to-control-surface, Markdown surface, and review-mechanics cases.

## Process issues

The interview loop had drifted into abstract taxonomy too early.

## Proposed follow-up improvements

- Keep scenario cards at the top until the user anchors on one.
- Consider making the scenario cards reusable in a template.

## Candidate ADR or implementation topics

- Reusable scenario card catalog.

## Current status

The interview flow is now scenario-first rather than purely abstract.
