# AAR 20260701.140853: Debt triage promotion

## Scope

Refined the control-surface interview to include debt triage and promotion rules.

## What happened

Captured the user's distinction between debt items and well-defined implementation tasks, and their desire for a triage system that combines, splits, and promotes debt items until some become ADR candidates. Updated the deep-interview skill to require a debt triage rule in the final decision summary.

## Process issues

No durable process issue observed.

## Proposed follow-up improvements

- Define concrete threshold criteria for promotion from debt item to implementation task or ADR candidate.
- Consider a small lifecycle model for debt register items.

## Candidate ADR or implementation topics

- Debt register lifecycle and promotion rules.

## Current status

Debt items are now part of the control-surface interview model.
